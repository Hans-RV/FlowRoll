# 🌀 FlowRoll

**FlowRoll** is a simple, open-source **lottery / lucky draw smart contract** built in **Solidity**, inspired by the **Flow blockchain** ecosystem and Roll on Flow.  

This project demonstrates how to implement a transparent, decentralized lottery mechanism that mimics common dApp patterns on Flow — while being deployable on EVM-compatible networks for learning and testing.

> 🧠 *FlowRoll is an educational project — not a production-ready dApp.*

---

## ✨ Features

- 🎟️ **Join the lottery** by paying a fixed ticket price.  
- 🏆 **Pick a random winner** and distribute the prize pool.  
- 🔁 Automatically resets after each round.  
- 🔐 Owner-only control for winner selection.  
- 🧮 Demonstrates pseudo-randomness (educational use).

---

## 🧠 Why “FlowRoll”?

- Inspired by **Roll on Flow** dApp patterns  
- Mimics on-chain game / reward mechanics  
- Bridges **Flow concepts** to **Solidity implementation**
